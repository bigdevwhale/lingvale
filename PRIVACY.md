# Privacy

Lingvale has no account, no ads and no analytics, and it doesn't ask for internet access.

It reads, on the phone, what the other -ling apps installed on the same phone show it through their bridge: their pets, the kinds of pets, which days something was done and the last week's events (for Pennyling, the category and the amount as Pennyling writes it). It keeps the last answer of each app in its own private storage so the village opens quickly. It sends nothing anywhere.

When you ask it to save a moving file, each app writes its own backup and Lingvale packs them into one file in the place you choose; that file holds everything those apps hold, so keep it as you would the apps' own backups. When you load a moving file and confirm, each ticked app replaces its data with its backup from the file. Apart from that, Lingvale changes nothing in those apps.

Uninstalling Lingvale deletes everything it kept.
